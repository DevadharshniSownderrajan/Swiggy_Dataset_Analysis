# Swiggy_Dataset_Analysis
# 🍔 Swiggy Food Delivery – SQL Practice

## 📌 About the Project

This project contains **150 SQL practice questions** based on a **Swiggy Food Delivery Management System**.

The main goal of this project is to practice SQL concepts using a real-world food delivery scenario and analyze data related to customers, restaurants, orders, payments, reviews, menu items, and deliveries.

## 🛠️ Tools Used

* MySQL
* MySQL Workbench
* SQL

## 📚 Topics Covered

### 1. Beginner SQL

* SELECT statements
* WHERE conditions
* DISTINCT
* ORDER BY
* LIMIT
* Filtering records
* Pattern matching using LIKE
* IN, NOT IN, BETWEEN
* Column aliases

### 2. Aggregate Functions

* COUNT()
* SUM()
* AVG()
* MAX()
* MIN()
* GROUP BY
* HAVING
* Rounding values

### 3. JOIN Queries

* INNER JOIN
* LEFT JOIN
* Joining multiple tables
* Combining customer, restaurant, order, payment, review, and delivery information
* Business reports using multiple tables

### 4. Date & Time Functions

* Current date and time
* YEAR()
* MONTH()
* DAY()
* WEEK()
* QUARTER()
* DATEDIFF()
* TIMESTAMPDIFF()
* DATE_ADD()
* DATE_SUB()
* DATE_FORMAT()

### 5. Advanced SQL

* Window Functions
* ROW_NUMBER()
* RANK()
* DENSE_RANK()
* NTILE()
* LAG()
* LEAD()
* Running totals
* Moving averages
* Common Table Expressions (CTEs)
* Subqueries
* CASE statements
* Conditional aggregation
* Customer Lifetime Value (CLV)
* KPI and business reports

## 📊 Business Analysis

The queries are designed to answer practical business questions such as:

* Which restaurants generate the highest revenue?
* How many orders does each customer place?
* What is the average rating of each restaurant?
* Which payment method generates the most revenue?
* Which delivery partner has the lowest average delivery time?
* Who are the top customers based on lifetime spending?
* What percentage of total revenue does each restaurant contribute?
